请为一个只面向 iOS App Store 上架、使用 SwiftUI 实现的 iPhone App 生成高保真 UI 原型。应用名为“凭保 Proofly”。

这是一个本地优先的重要资料富媒体备忘录。用户可以像写备忘录一样先保存一条记录：文字、照片、合同、票据、证照、保修卡、体检报告、检查单、处方、疫苗记录、付款截图、PDF 和普通文件都可以放进去。用户后续可以按资料箱、相关人或物、事件和提醒整理，需要时打包导出资料包。

请生成一个贴近 iOS 18 / SwiftUI 原生风格、但明显更现代、更简洁、更酷、更适合海外 iOS 用户审美的 iPhone App 原型。整体风格应像一个 premium personal utility App：冷静、可信、轻未来感、精致但不浮夸。

如果你只能生成 HTML / React / Tailwind 预览，也必须模拟 SwiftUI 原生 App 的视觉和交互。结果必须看起来是 iPhone App，不是 Web App、后台系统、H5、小程序或 Android App。

## 1. 设计目标

- 只设计 iPhone App，画布以 iPhone 15 / 390x844 为主。
- 视觉必须像 iOS SwiftUI 原生 App，而不是 Android / Material Design。
- 第一屏就是可用 App 界面，不要生成营销落地页、官网或产品介绍页。
- 交互必须简洁，减少一级入口和复杂管理感。
- 底部 Tab 必须只有 4 个：首页、记录、提醒、设置。
- 对象不作为底部一级 Tab，只从首页、搜索、记录详情或资料包导出流程进入。
- 所有字段都可选，用户可以只写一句话、只拍照或只导入文件后直接保存。
- 首版不做 OCR，不要出现“自动识别”“AI 提取”“扫描识别”等入口。
- 产品本地优先：不登录、不上传、不默认云同步、不接广告。
- 文案使用简体中文，少量英文只用于品牌名 Proofly、PDF、ZIP 等必要格式名。
